 Portfólio Pessoal – Parte 1

 1. Descrição

Pokémon Hero Profile

Projeto acadêmico desenvolvido em HTML e CSS com o tema Pokémon.

A ideia do projeto é apresentar uma ficha de treinador e uma Pokédex simples, com informações sobre o personagem, seus atributos, habilidades, itens e Pokémon encontrados durante a jornada.

O site apresenta o treinador Murilo Gandolfi como um mestre Pokémon especializado em estratégia.

A página principal funciona como uma ficha do personagem, enquanto as outras páginas organizam as informações da Pokédex.

 4. Instruções de uso

Para executar o projeto, abra o arquivo:

index.html

Basta clicar duas vezes no arquivo index.html para abri-lo no navegador.

Também é possível utilizar o projeto através do Visual Studio Code, utilizando uma extensão como o Live Server.

Não é necessário instalar ou configurar um servidor, banco de dados ou outras ferramentas para executar o projeto.

5. Tecnologias e recursos utilizados

* HTML5
* CSS3
* Font Awesome
* Google Fonts

 7. Design

O visual foi inspirado no universo Pokémon, utilizando principalmente:

Azul escuro para o fundo;
Amarelo inspirado no Pikachu;
Azul claro para detalhes e destaques;
Cards para organizar as informações;
Ícones do Font Awesome;
Fonte Orbitron para títulos;
Fonte Roboto para os textos.

Também foi utilizada uma imagem de batalha como fundo da página principal para deixar a ficha do treinador mais temática.

 8. Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela.

Foram adicionados ajustes específicos para:

Computadores; 
Tablets;
Celulares.

No celular, os conteúdos passam para uma única coluna e o menu é reorganizado para facilitar a navegação.

 9. Objetivo

O objetivo principal é praticar a criação de páginas web utilizando HTML e CSS, trabalhando conceitos como:

Estrutura semântica;
Flexbox;
CSS Grid;
Responsividade;
Links entre páginas;
Organização de conteúdo;
Estilização de componentes.

 10. Créditos

As imagens dos Pokémon utilizadas nas páginas são fornecidas pela **PokéAPI**.

Projeto desenvolvido para fins acadêmicos.
